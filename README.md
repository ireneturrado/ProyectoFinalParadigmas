## Descripción del proyecto
CastleEscape: es un videojuego desarrollado en Unity en el que el jugador controla un cowboy que debe escapar de un castillo medival vigilado por distintos drones con distintos comportamientos inteligentes.

El proyecto se centra en el diseño de la arquitectura del sistema, aplicando principios SOLID, patrones de diseño y una clara separación de responsabilidades, con el objetivo de lograr una solución modular, mantenible y extensible.

Esta entrega corresponde a la Primera Parte del Proyecto Final: Diseño de Arquitectura.

## Contenido del repositorio
El repositorio contiene exclusivamente los elementos necesarios del proyecto Unity, siguiendo buenas prácticas de control de versiones.

### Estructura del proyecto Unity

Las carpetas generadas automáticamente por Unity (Library, Temp, Logs, UserSettings, Obj, etc.) han sido excluidas mediante el archivo `.gitignore`, tal y como se recomienda para proyectos Unity versionados con Git.

## Diagrama UML
El repositorio incluye un diagrama UML completo que describe la arquitectura del sistema y los principales módulos del proyecto:

- Inteligencia artificial de los drones y máquina de estados  
- Sistema de detección de ruido  
- Sistema de dificultad  
- GameManager y control del flujo de la partida  
- UIManager, sistema de puntuación y sistema de sonido  

Archivo:
